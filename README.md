Практическое задание: Изучение графов и Git

1. Теория графов и алгоритмы

1.1. Структура графа

Граф — это способ представления объектов и отношений между ними. Основными элементами графа являются вершины и рёбра.

Где можно встретить графы:

* В навигационных приложениях.
* В социальных платформах.
* В схемах подключения устройств.
* В системах поиска информации.

1.2. Графы с направлением связей

Ориентированный граф отличается тем, что его рёбра показывают направление перехода между вершинами.

Например, связь между двумя объектами может разрешать переход только от первого объекта ко второму.

Такие графы применяются:

* Для описания переходов на интернет-страницах.
* При построении последовательностей действий.
* Для отображения зависимостей в программировании.

1.3. Использование весов в графах

В некоторых графах связи имеют дополнительные числовые характеристики. Такие графы называются взвешенными.

Числовое значение ребра называется весом.

В качестве веса могут использоваться:

* Дистанция между объектами.
* Продолжительность поездки.
* Цена перемещения.
* Количество необходимых ресурсов.

Взвешенные графы помогают сравнивать различные варианты и выбирать подходящий путь.

1.4. Алгоритм BFS

BFS (поиск в ширину) — метод обхода графа, при котором исследование начинается с одной вершины и постепенно распространяется на соседние уровни.

Для организации обхода применяется структура данных «очередь».

Главные свойства BFS:

* Начинает работу с указанной вершины.
* Сначала рассматривает ближайших соседей.
* Использует очередь для хранения вершин.
* Позволяет определить кратчайшее расстояние в количестве рёбер в невзвешенном графе.

2. Работа с системой Git

2.1. Возможности системы Git

Git — это система, предназначенная для отслеживания изменений в программных проектах.

Она помогает разработчикам сохранять результаты работы и контролировать развитие проекта.

Основные возможности:

1. Ведение истории изменений.
2. Хранение разных версий проекта.
3. Восстановление предыдущих состояний.
4. Параллельная разработка функций.
5. Обмен изменениями между участниками команды.
6. Объединение результатов работы.

2.2. Разработка с помощью веток и коммитов

В Git используются два важных понятия: ветки и коммиты.

Ветка (Branch) — отдельная линия разработки. Она позволяет экспериментировать с кодом или добавлять новые возможности, не затрагивая основную ветку.

Примеры:

* main — главная версия проекта.
* dev — ветка для разработки.
* feature — ветка для реализации новой функции.

Коммит (Commit) — запись, которая фиксирует определённые изменения в репозитории. Коммиты позволяют просматривать историю разработки.

Пример:

git add .
git commit -m "Обновление проекта"

3. Примеры команд Git

Команда Назначение
git init Создаёт новый репозиторий
git add . Добавляет изменения в индекс
git commit -m "Текст" Сохраняет изменения
git branch Показывает список веток
git switch -c dev Создаёт новую ветку и переключается на неё
git push Отправляет изменения на сервер
git pull Получает изменения с сервера
