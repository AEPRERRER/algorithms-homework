Домашнее задание по алгоритмам и Git

1. Алгоритмы

1.1. Графы

Граф — это структура данных, состоящая из вершин и рёбер, которые соединяют вершины между собой.

Графы используются:

 В социальных сетях.
 В картах и навигации.
 В компьютерных сетях.
 Для поиска маршрутов.

1.2. Направленные графы

Направленный граф — это граф, в котором каждое ребро имеет определённое направление.

Например, если есть связь из вершины A в вершину B, это не означает, что можно перейти из B в A.

Применение:

Ссылки между сайтами.
 Зависимости между задачами.
 Схемы движения.

1.3. Веса графов

Взвешенный граф — это граф, в котором каждому ребру присвоено числовое значение, называемое весом.

Вес может обозначать:

Расстояние.
Время.
Стоимость.
Длину маршрута.

Взвешенные графы помогают находить наиболее короткие и выгодные маршруты.

1.4. Поиск в ширину (BFS)

BFS (Breadth-First Search) — алгоритм обхода графа в ширину.

Он сначала проверяет ближайшие вершины, а затем переходит к более удалённым.

Особенности алгоритма:

 Использует очередь.
 Обходит вершины по уровням.
 Находит кратчайший путь в невзвешенном графе.
 Позволяет проверять связи между вершинами.

2. Git

2.1. Какие задачи решает Git?

Git — это система контроля версий, которая помогает разработчикам управлять изменениями в программном коде.

Основные задачи Git:

1. Сохранение истории изменений проекта.
2. Возврат к предыдущим версиям файлов.
3. Совместная работа нескольких разработчиков.
4. Создание отдельных веток для новых функций.
5. Объединение изменений.
6. Отслеживание ошибок и изменений в проекте.

2.2. Что такое ветки и коммиты?

Ветки (Branches) — это отдельные линии разработки проекта. Они позволяют работать над новыми функциями, не изменяя основную версию программы.

Примеры:

main — основная ветка.
feature — ветка для разработки новой функции.
bugfix — ветка для исправления ошибок.

Коммиты (Commits) — это сохранённые изменения проекта. Каждый коммит содержит информацию о том, какие изменения были сделаны.

Пример создания коммита:

git add .
git commit -m "Первый коммит"

3. Основные команды Git

git init

Создание локального репозитория.

git add .

Добавление файлов для сохранения.

git commit -m "Первый коммит"

Сохранение изменений.

git branch

Просмотр веток.

git switch -c feature

Создание новой ветки.

git push

Отправка изменений на удалённый сервер.

git pull

Получение изменений с удалённого сервера.

4. Вывод

Git является важным инструментом для программистов. Он позволяет сохранять историю проекта, работать в команде и контролировать изменения.

Графы и алгоритм поиска в ширину используются для решения различных задач, поиска связей и построения маршрутов.
